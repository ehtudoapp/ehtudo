Sobre a aplicação

O Passa Régua é uma aplicação web mobile-first para divisão inteligente de despesas entre amigos, similar ao Splitwise. Com sincronização de grupos entre dispositivos via PocketBase.

Registre as despesas do grupo, informe quem pagou e o valor — o sistema calcula automaticamente o acerto de contas usando um algoritmo que minimiza o número de transações necessárias, evitando voltas desnecessárias do dinheiro.

Ideal para viagens em grupo, repúblicas, casais e eventos. Chega de confusão e cobranças constrangedoras!

Vue 3 TypeScript Tailwind CSS PocketBase Mobile-first

Como funciona

Algoritmo de liquidação inteligente

O Passa Régua calcula os saldos líquidos de cada participante — quem pagou mais do que devia (credor) e quem pagou menos (devedor). Em seguida, cruza o maior devedor com o maior credor realizando a maior transferência possível entre eles, repetindo o ciclo até zerar todos os saldos. Isso garante o número mínimo de transações.


Exemplo: Alice pagou R$ 150, Bob pagou R$ 90, Carol não pagou nada. Total: R$ 240 (R$ 80 por pessoa). Em vez de 3 transferências, o sistema resolve em apenas 2: Carol → Alice R$ 70 e Carol → Bob R$ 10.

Funcionalidades

Grupos com sincronia

Crie grupos para viagens e eventos. Os dados sincronizam entre dispositivos em tempo real via PocketBase.

Registro de despesas

Registre data, valor, quem pagou e descrição. Divida igualmente, por porcentagem ou por valor fixo.

Saldos automáticos

Veja o saldo de cada participante (verde = credor, vermelho = devedor) e as transações sugeridas para zerar as contas.

Registro de pagamentos

Registre pagamentos diretos entre membros para quitar as dívidas conforme as sugestões do sistema.

Mobile-first

Interface projetada para celular com botões FAB, drawers e navegação por abas — funciona em qualquer dispositivo.

Sincronização entre dispositivos

Compartilhe o grupo com outros participantes e todos veem as despesas e saldos atualizados em tempo real.
